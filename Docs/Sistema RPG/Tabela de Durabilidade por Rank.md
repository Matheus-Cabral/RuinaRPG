Durabilidade máxima de Armas, Armaduras e Escudos conforme o Rank do item. Itens sem Rank não têm durabilidade. Os valores podem ser ajustados pelo Auditor de Regras (ver [[Requisitos - Auditoria de Regras]]).

| Rank | Durabilidade |
| ---- | ------------ |
| F    | 20           |
| E    | 45           |
| D    | 80           |
| C    | 125          |
| B    | 180          |
| A    | 245          |
| S    | Inquebrável  |
| SS   | Inquebrável  |
